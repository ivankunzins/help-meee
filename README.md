# SECRET VILLAGE — Roblox

Исследовательская multiplayer-игра: деревня, 30 минут на поиск тайн, экономика, работы, транспорт, события и коллекция из 100 секретов.

## Уже реализовано
- ⏱️ персональный 30-минутный таймер;
- 💰 серверная экономика и сохранение;
- 🧹 работа дворника: 80 листьев по $1;
- 🎣 работа рыбака: 16 мест по $8;
- 🍎 еда, продавец и доставка;
- 🌊 река и подводная секретная комната;
- 🔐 100 точек секретов;
- 📖 книга коллекции 1–100;
- 💾 отдельное сохранение каждой найденной тайны;
- 🚗 машина, такси и фургон с сохранением покупок;
- 🤝 кооперативный секрет #011;
- 🌙 ночь, туман, blackout и торговые события;
- 🛍️ магазин исследовательских предметов;
- 🎯 ежедневные задания;
- 🏆 достижения и прогресс;
- 📱 единый HUD для телефона и PC.

## Структура
Все серверные системы находятся в `src/ServerScriptService`. Клиентский HUD — в `src/StarterPlayer/StarterPlayerScripts`. Конфигурация — в `src/ReplicatedStorage/SecretVillage`.
