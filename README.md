Первая версия игры: деревня, 30-минутный раунд, деньги, продавец, подсказки, работа дворника и секретная дверь под водой.

## MVP
- 30:00 раунд
- 2 водоёма
- секретная комната в реке
- продавец еды
- подсказка за $500
- работа дворника за $100
- листья: $1 за штуку
- сохранение денег и прогресса
